**BLOOMWARD** is an original garden tower defense that runs in a desktop browser from static files — no build step, no network requests. Bugs march a sandy path toward the Heartbloom; you plant flower towers on the lawn to stop them. Petal Poppies sting fast, Thorn Roses hit hard, Frost Mint chills the parade to half speed, and Boom Melons splash whole crowds. Squished bugs pay back sunlight, sunlight buys more flowers and upgrades (three levels each), and the garden stands or falls over 12 hand-tuned waves that end with the Brute Beetles. It is complete: title screen, planting and wave HUD, score, a win card and a defeat card, and restart — with synthesized WebAudio sound and a seeded garden that grows the same lawn every time.

Controls: mouse to plant and select · keys 1–4 pick a flower · Space sends the next wave · F fast-forward · P pause · M sound · R restarts from the end cards.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8123 in a desktop browser. (Any static file server pointed at `game/` works just as well; `main.ts` is the hand-in program that packages `game/` and `screenshots/` into a make.fun dossier.)
